# Quickstart: Modern 3D Menu System

## Prerequisites

- Node.js 18+ installed
- npm available in the shell
- Local project checkout

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open the Vite-served local URL in the browser.

## Production build

```bash
npm run build
```

The static build output will be generated in the Vite output directory and can be published to a static host.

## Manual validation

1. Load the app and confirm the ultra-wide layout renders as intended.
2. Use keyboard controls to move across the root menu.
3. Press Enter to select an item and confirm nested submenus render.
4. Press Delete or select Back and press Enter to return to the parent menu.
5. Confirm the Three.js scene loads the Mesy_AI_Racing_Simulator asset and the camera gently pans around it.
6. Confirm the static build runs without any runtime server dependency.
